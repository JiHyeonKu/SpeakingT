# 기존 Daily English Training에 연결

현재 템플릿의 독해·어휘·문법·작문 흐름은 유지하고 ⑤와 ⑥에 녹음 분석을 붙인다. 여기서는 사용자가 제공한 과제의 핵심만 반영한다. 개인 전체 대화나 채점 이력은 저장소에 복제하지 않는다.

## 매일 반복할 흐름

1. **첫 답변:** 모범 답안 없이 ⑤ 일상 상황 30–60초, ⑥ 학술 상황 30–60초를 각각 녹음한다. 멈춤·반복도 원본에 남긴다.
2. **내용 확인:** 사용자가 들으며 ASR 전사를 확인한다. 기존 ChatGPT 흐름에서 문법·표현·상황 적합성 피드백을 받는다.
3. **음성 확인:** SpeakingT가 원본의 휴지 시점·음높이 변화를 보여준다. 실제 발음 평가는 검증된 모델/API를 사용한 경우만 따로 표시한다.
4. **짧게 교정:** 오늘 교정할 항목 1–2개를 고르고, 교정 문장 10–20초를 읽는다. 읽기는 정확한 목표 문장으로 평가하기 쉽다.
5. **재녹음:** 같은 문장을 다시 읽고, 새로운 상황에도 표현을 적용한다. 암기 개선과 실제 전이 능력을 구분한다.

## Day 1 연결 예시

### ⑤ Everyday Speaking

상황: Alex가 약속을 반복해서 취소했다. 공감하면서 불편함을 표현하고 다음 약속에 관한 제안을 한다. 첫 답변은 2–4문장으로 자유롭게 녹음한다.

읽기 재연습용 목표 문장:

> I get that things come up, but it's getting a little frustrating when our plans keep getting canceled.

피드백은 문법·친근함·단호함과 별도로, 문장 중간에 끊긴 구간을 들으며 확인한다. 자연스러운 의미 단위의 쉼은 오류로 간주하지 않는다. 감정이나 강조에 따라 억양이 달라질 수 있다.

### ⑥ Academic Speaking

상황: 보조 기기의 객체 탐지 모델에서 정확도보다 가벼운 모델을 선택한 이유를 설명한다. Constraint → Decision → Trade-off → Justification 순서로 3–4문장 자유 답변을 녹음한다.

읽기 재연습용 목표 문장:

> Given the hardware constraints, we prioritized real-time processing over a small improvement in accuracy.

핵심 개념을 듣기 쉽게 강조하는지 사람과 비교해 확인한다. 내용의 전문성이나 논리는 pitch 범위로 채점하지 않는다.

## 결과 기록

각 세션에 `date`, `task_type`, `prompt_id`, `take_id`, 원본 해시, 전사 확인 여부, 측정기/평가기 버전, 수정한 목표, 다시 말하기 결과를 남긴다. 처음에는 HTML/JSON 파일로 기록하고, 이후 누적 대시보드를 추가한다.

읽기 객관식 정확도와 말하기 점수를 하나의 퍼센트로 섞지 않는다. 읽기·내용·발음·유창성 각각의 추세를 기록한다. 최근 3–5회 비교는 같은 과제 유형과 비슷한 녹음 환경에서 하되, 자동 난이도 조정은 충분한 관찰 후 도입한다.

기존 오후 8시 알림의 자동 연결은 아직 구현하지 않았다. 첫 버전은 알림으로 연습을 시작하고, 원본 WAV를 SpeakingT로 분석한 결과를 함께 확인하는 방식이다.
