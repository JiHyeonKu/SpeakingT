# 현재 상태

2026-10-28 · v0.1.0 · M4A 입력과 첫 개인 음성 분석

## 완료

- 실현 가능성 검토, 공식 데이터·라이선스 조사, 총 50달러 범위의 로드맵.
- 원본 PCM WAV의 품질·휴지·F0 측정, 상대 음높이 그래프, HTML/JSON 보고서.
- 전사의 filler·반복·한국어 후보. 음성 기반 완전 검출은 아님.
- 녹음/구간 추출/로컬 ASR 선택 인터페이스와 Azure 읽기 평가 어댑터.
- 사람 평가를 학습하는 선형 유창성 기준선, 조기 종료, 화자 분리, 중복 해시 검사.
- 실제 SpeechOcean762 음성 300개와 전문가 점수 다운로드 및 파일럿 학습. 원본과 캐시는 로컬 `data/`에만 보관.
- 학습 190개/40명, 검증 47개/10명, 시험 46개/10명. 불안정한 pitch 17개 제외.
- 2,000 epoch 상한, patience 100. 507회 종료, 검증 최적 407회 선택.
- 시험 MAE 10.097/100. 평균 기준선 11.913, **중앙값 기준선 10.217**. 중앙값 대비 개선이 작으므로 강한 성능 증거로 해석하지 않음.
- 기본·통합·데이터 수집·외부 API 모의 요청 테스트 61개 통과(Windows/Python 3.11.4/NumPy 2.4.6).
- 사용자 템플릿의 ⑤ 일상 대화·⑥ 학술 발표에 연결하는 훈련 절차 문서화.
- 선택적 M4A 등 음성 가져오기: 원본 보존, mono/16kHz/PCM16 변환, SHA256·코덱·시간 오프셋 기록, 무음 유지.
- 사용자 제공 음성의 실제 로컬 변환·음향 측정·오프라인 ASR 전사 실행. 개인 보고서에 녹음 재생·관찰 구간 탐색과 별도 영문 청취 평가 양식을 제공. 원본·전사·측정값은 공개 저장소에 포함하지 않음.
- 로컬 전사 환경: faster-whisper 1.2.1, small 모델, CPU int8, PyAV 18.1.0. 원고를 전사 힌트로 제공하지 않으며 전사 결과는 사람 확인 전 추정치로 표시.
- M4A 변환 회귀 테스트 14개를 포함한 전체 테스트 75개 통과. 실제 파일의 48kHz stereo AAC → 16kHz mono PCM 변환과 원본 해시 보존 확인.

실험 상세와 재현 명령은 [파일럿 기록](../experiments/fluency-pilot/README.md)에 있다.

## 아직 완료하지 않은 것

- 사용자 음성의 사람 청취 평가와 음소 정확도 검증. 첫 측정·전사 실행은 완료했지만 발음 교정 성능을 입증한 것은 아님.
- 검증된 음소 오류 진단, 음절 강세/리듬 교정, 자유 발화의 음성 기반 filler 탐지.
- 로컬 사전학습 음향 모델 또는 GOP를 통한 실제 발음 교정. 현재 로컬 학습 모델은 유창성 통계 기준선이다.
- Azure 실제 서비스 호출, 마이크 녹음의 장치 검증.
- 한국인 성인 데이터에 대한 검증, 미학습 문장 평가, 사람 평가와의 일치도 및 장기 개선 검증.
- 기존 오후 8시 알림과 자동 연동, 누적 대시보드.

## 지출

이번 작업에서 유료 API·클라우드 GPU 사용액: **$0**. 설정한 외부 지출 상한: **$50**. 기존 PC·인터넷·Codex 구독 비용은 이 실험 지출에 포함하지 않는다.

무료 원어민 청취 평가 참여 가능성을 반영해 **GPU 실험 $30 / 평가 API $10 / 예비비 $10 / 사람 평가 $0**으로 배분했다. 참여와 평가 데이터 확보는 아직 완료되지 않았다. 최초 유료 실험은 GPU 최대 $10, API 최대 $5로 제한하고, 검증 결과를 보고 남은 한도 사용을 결정한다. 이번 변경은 계획 갱신이며 지출은 발생하지 않았다.

## 다음 실험

첫 개인 분석의 관찰 구간을 원음과 함께 확인하고, 모델 결과를 먼저 보지 않은 원어민의 청취 평가를 수집한다. 같은 과제의 짧은 재녹음과 새로운 문장으로 개선 여부를 따로 확인한다. 음소 수준 진단은 별도의 사전학습 음향 모델/평가 서비스와 사람 확인을 추가한 후 제공한다. 품질을 검증하지 못한 유창성 파일럿 점수를 개인 발음 성적처럼 제공하지 않는다.
