# 실행 가능성과 개발 로드맵

2026-10-28 예산 개정 · 총 외부 지출 예산: USD 50 · 초기 실행: 로컬 CPU

## 판단

개인용 영어 말하기 튜터는 가능하다. 그러나 수십억 녹음으로 대형 음성 모델을 처음부터 학습하는 계획은 이 예산 범위에 맞지 않는다. 기존 음성 모델을 활용하고, 정답 라벨과 검증에 집중해야 한다. 현재 준비 중인 작은 통계 모델은 전체 목표를 대체하지 않고, 가장 싼 방법으로 가설을 검증하는 기준선이다.

사용자가 말한 “마땅한 정답 발음”은 **목표 발음(target pronunciation)** 또는 **참고 발음(reference pronunciation)**이라 부를 수 있다. 목표는 General American 계열의 선호 발음으로 설정하되 여러 허용 가능한 변이를 포함한다. 대화의 감정·문장 의미·강조에 따라 억양이 달라지므로 유일한 정답 파형은 없다.

또한 음성 입력이 모두 텍스트 변환만으로 작동하는 것은 아니다. 공식 OpenAI 문서에는 음성을 직접 다루는 대화 경로와 전사 경로가 구분되어 있다. 하지만 보내준 텍스트 피드백만으로는 원래 발음의 타당한 평가가 불가능하다. [공식 음성 문서](https://developers.openai.com/api/docs/guides/audio)

## 단계별 완료 조건

| 단계 | 결과물 | 완료 판정 |
|---|---|---|
| 0. 기준 고정 | 발음·유창성·내용을 구분한 평가표, 녹음 규격, 예산 | 동일 녹음의 반복 분석 재현 |
| 1. 로컬 수집·측정 | 원본 WAV, 휴지 시간, F0 그래프, 전사 후보, 구간 추출 | 무음·잡음·잘못된 WAV에서 잘못된 점수 대신 유보 |
| 2. 실제 데이터 기준선 | 사람이 채점한 공개 데이터 일부로 학습, 별도 화자 검증·시험 | 검증으로만 epoch 선택, 시험 MAE와 평균 기준선 및 제외율 공개 |
| 3. 음소 발음 분석 | 사전학습 음향 모델 + 강제 정렬 + GOP/평가 전용 head, 또는 검증된 평가 API | 한국인 학습자의 전문가 음소 라벨과 정밀도·재현율 비교 |
| 4. 억양·말버릇 | 음절 강세, 단어 길이, 문장 내 F0 궤적, filler/반복/언어혼용의 음성 기반 탐지 | 수동 타임스탬프와 event F1, 자연스러운 쉼에 대한 오탐 보고 |
| 5. 개인 검증 | 읽기·일상 대화·학술 발표 원본, 재녹음 쌍, 처음 보는 문장 | 사용자가 납득하는 시간 위치/피드백, 사람 평가와 일치·불일치 사례 |
| 6. 반복 훈련 | 기존 Daily English Training에 결과 연결, 최근 3–5회 추세 | 학습한 문장과 새로운 문장의 개선을 따로 확인 |

기간은 구현 가설상 1–2단계 며칠, 3–4단계 수주, 5–6단계 지속 반복이다. 외부 라벨·GPU·녹음 품질에 따라 달라지며 일정 약속이 아니다.

## 권장 분석 구조

원본 음성 → 녹음 품질 확인 → 병렬 처리:

1. 축어 전사와 언어 혼용 후보. ASR이 삭제한 음은 별도의 음성 기반 탐지로 보완한다.
2. 읽기 연습은 주어진 문장, 자유 발화는 수동 확인한 전사를 기준으로 정렬한다.
3. 음소 단위 음향 증거로 발음 평가. 강제 정렬은 시점을 맞추는 기술이며, 자체가 정확한 발음이라는 증거는 아니다.
4. F0·energy·길이·강세·휴지를 문장/음절 수준으로 분석한다. FFT는 신호 도구이지 억양 정답 판정기가 아니다.
5. 근거 시점, 후보 오류, 추정 신뢰도, 연습 방법을 한국어로 작성한다. 잡음/정렬 실패는 채점 유보한다.

초기 참고 음성은 동일 문장의 여러 실제 화자를 권장한다. TTS는 연습 예시로 표시하고 객관적 정답 데이터로 취급하지 않는다. 원어민 대규모 데이터는 음성 표현 학습에 유용하지만, 학습자 오류를 교정하려면 오류 종류와 사람 평가가 필요하다.

## 학습과 성공 판정

epoch를 최대화하는 것은 목표가 아니다. 적은 데이터에 오래 학습하면 과적합할 수 있다. 검증 성능으로 학습률·정규화·학습 종료를 선택하고, 선택이 끝난 모델만 독립 시험에서 평가한다.

검증 지표는 목적별로 다르다: 유창성 MAE/상관, 음소 오류 precision/recall, filler event F1, 반복 녹음의 안정성, 사람 간 평가 일치도, 한국 화자 오탐률. 임의의 '원어민 87점'이나 단순 파형 유사도는 성공 지표로 쓰지 않는다.

첫 개인 테스트는 같은 환경에서 10개 짧은 읽기 문장 + 30–60초 일상 답변 + 30–60초 프로젝트 발표. 미국 영어 원어민 평가자가 무료로 참여할 수 있다는 조건을 반영해 초기 청취 평가를 계획한다. 원어민 유사성과 이해 용이성은 별도 항목이다. 휴지나 억양만으로 CEFR 수준을 자동 판정하지 않는다.

무료 평가자의 평가는 다음과 같이 활용한다. 이는 참여 가능성을 전제로 한 계획이며 아직 평가를 수행한 것은 아니다.

- 먼저 원고와 모델 점수를 보지 않고 들리는 내용을 적거나 이해하기 어려웠던 구간을 표시한다. 이후 원고를 보고 어색하게 들린 단어·강세·쉼을 확인한다.
- 이해하기 쉬움, 자연스러움, 과도한 머뭇거림을 구분해 같은 평가표로 기록한다. 판단하기 어려운 항목은 보류한다. 원어민이라는 이유만으로 전문 음소 오류 라벨을 확정하지 않는다.
- 교정 전후 녹음의 순서를 섞어 어느 것이 재녹음인지 숨기고, 일부 녹음은 다른 날 다시 평가해 같은 평가자의 일관성을 확인한다.
- 참고 문장을 직접 읽어줄 수 있다면 하나의 허용 가능한 발음 예시로 사용한다. 그 화자의 모든 억양을 유일한 정답으로 학습하지 않는다.
- 초기 결과는 한 명의 익숙한 청자에게서 얻은 개인 평가로 보고한다. 일반화 성능을 주장하려면 추가 독립 평가와 별도의 시험 음성이 필요하다. 학습에 사용한 평가를 최종 시험에 재사용하지 않는다.

## 50달러 예산 배분안

미국 영어 원어민 평가자가 초기 청취 평가를 무료로 도와줄 수 있다는 전제로 인건비를 $0으로 조정했다. 기존 원어민 검토/예비비 $20 중 $10을 GPU 실험에 추가하고 $10은 예비비로 남긴다. 다음은 **지출 상한 배분안**이며 서비스 가격 인용이나 선결제 계획이 아니다. 현재 유료 서비스는 호출하지 않는다.

|---|---:|---|
| 로컬 측정·공개 데이터 소규모 학습 | $0 | CPU와 기존 디스크 사용 |
| 원어민 청취 평가·가능한 참고 녹음 | $0 | 평가자의 무료 참여를 전제로 하며, 참여 범위는 실제 가능한 만큼 확보 |

현재 네 가지 음향 특징 모델의 작은 개선은 GPU나 epoch만 늘리면 해결된다는 근거가 아니다. 먼저 사전학습 음향 표현·정렬을 추가할 가설과 평가 데이터를 정하고, 무료 로컬 실험이 가능한 범위는 로컬에서 실행한다. 미사용 예산은 남겨두며 전액 소진을 목표로 하지 않는다.

이 코드에는 클라우드 지출을 자동 차단하는 계정 수준 기능이 없다. 유료 실험 전 제공자 예산 설정과 실제 단가를 확인하고, 실험별 최대 음성 길이/호출 수/학습 시간을 정한다. 한 명의 청취 평가로 판단하기 어려운 음소 전문 라벨이나 일반화 검증은 별도로 확보하거나, 가능한 평가 범위를 명시한다.

## 아직 필요한 입력

- 사용자의 실제 PCM WAV 녹음. 텍스트만으로 발음 테스트를 대신할 수 없다.
- 무료 로컬 범위를 넘어 평가 API를 사용할 경우 해당 서비스 계정/키.
- 실제 사용 중 원하는 참고 발음/화자와 우선 교정할 현상. 초기 기본값은 이해 용이성·긴 휴지·미국 영어 읽기다.
