## 시작

현재 Windows 작업 공간에서는 프로젝트 폴더의 `start-gopt.cmd`를 실행한다.
JupyterLab이 로컬 주소에 열리고 `notebooks/SpeakingT_GOPT.ipynb`를 표시한다.
노트북의 첫 셀부터 Shift+Enter로 진행한다. 전체 실행은 기본 10 epoch 학습까지 실행한다.
학습을 중단할 때는 노트북의 ■ 버튼을 누른다. 서버 종료는 실행 창의 Ctrl+C 또는
JupyterLab의 File → Shut Down 메뉴를 사용한다.

새 환경은 Python 3.11 이상에서 다음과 같이 설치한다. GPU가 없어도 작동한다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install "torch>=2.6,<3" --index-url https://download.pytorch.org/whl/cpu
.\.venv\Scripts\python.exe -m pip install -e ".[research]"
.\start-gopt.cmd
```

Colab에서는 저장소의 같은 노트북을 열어 첫 셀을 실행한다. 로컬 CPU 경로는 실제 검증하며,
Colab/GPU 경로는 이 PC에서 실행하지 않았다. 별도 유료 런타임 가입은 필요 조건이 아니다.

## 실제로 학습하는 것

```text
공개 음성 → 기존 LibriSpeech 음향 모델·정렬 → 저장된 84차원 GOP 특징
                                                   ↓
                          고정 음소 ID + GOPT Transformer
                                                   ↓
                         음소 / 단어 / 문장 점수 예측
                                                   ↓
                          사람 점수와 MSE → 역전파
```

이번 노트북은 **이미 저장된 특징부터** 실행한다. GOPT 코드 구조는 저자 버전 그대로다.
음소 출력, 단어의 정확도/강세/종합, 문장의 정확도/완전성/유창성/운율/종합을 예측한다.
운율 점수는 개별 강세 오류의 위치나 F0 교정 지시를 자동으로 입증하지 않는다.

공식 가중치를 불러오는 셀과 새 가중치로 재학습하는 셀을 구분한다. 재학습은 작은
평가 모델에 한정된다. 기반 음향 모델을 새로 학습하거나 사용자의 녹음으로 학습하지 않는다.
공개 가중치는 공식 train 전체를 이미 보았으므로 독립 validation 실험의 초기값으로 쓰지 않는다.

## 학습과 기록

공식 train 125명/2,500개 중 seed를 이용한 화자 ID 해시 순서로 25명/500개를 validation으로
고정한다. 점수는 분할 선택에 사용하지 않는다. 나머지 100명/2,000개로 학습한다.
공식 test 125명/2,500개는 학습에서 읽지 않는다. 화자는 분리되지만 문장 중복은 있을 수 있다.

입력 표준화는 학습 화자의 유효 음소만으로 계산한다. 평가 시 음소 padding은 손실/지표에서 제외하고,
단어 점수는 같은 단어의 음소별 출력을 평균한다. 음소는 0–2, 단어/문장은 0–10 단위로 보고한다.
PCC는 Pearson 상관계수이며 정답률이 아니다. 상관을 계산할 수 없는 경우 `null`이다.

자체 루프는 원본 GOPT 구조·합산 MSE·Adam을 사용한다. 독립 validation, 일정 learning rate,
조기 종료를 추가하므로 원본 warm-up/스케줄러/시험 점수 기반 선택 루프와는 다르다.
모델 선택 지표는 validation 음소 MSE다. 따라서 운율에 최적화한 모델이라고 주장하지 않는다.

`runs/gopt/<run>/`에 다음을 기록한다.

| 파일 | 확인할 내용 |
|---|---|
| config.json / split.json | seed, learning rate, 환경 버전, 특징 표준화, 화자·발화 분할 |
| metrics.csv | epoch 0부터 학습/검증 MSE, PCC, 가중치 변화량, 경과 시간 |
| metrics-NNN.json | 음소·단어·문장별 상세 평가 |
| epoch-NNN.pt / best.pt | 모델·optimizer 상태와 해당 epoch; validation으로 best 선택 |
| tensorboard/ | 여러 실험을 비교하는 실시간 그래프 |
| summary.json | 완료/조기종료/중단 상태와 best epoch |

epoch 0은 학습 전 기준선이다. checkpoint 재로딩과 비교는 제공하지만, 중간 optimizer 상태를
불러와 이어 학습하는 기능은 아직 제공하지 않는다. 재실행은 새 run으로 시작한다.
노트북의 최종 test 셀은 기본 비활성화다. 설정 선택을 마친 뒤에만 직접 실행한다.
