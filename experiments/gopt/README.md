## 공식 가중치 평가

공식 GOPT LibriSpeech 체크포인트(26,577 파라미터)를 불러와 공식 SpeechOcean762
test 2,500개/125명에서 실행했다. 모델 구조와 가중치를 변경하지 않았다.

| 지표 | 실행 결과 | 저자 공개 best 체크포인트 설명 |
|---|---:|---:|
| 음소 MSE, 0–2 단위 | 0.08347 | 0.084 |
| 음소 PCC | 0.61832 | 0.616 |
| 문장 정확도 PCC | 0.71787 | 0.718 |
| 문장 유창성 PCC | 0.75615 | 0.756 |
| 문장 운율 PCC | 0.76477 | 0.764 |
| 문장 종합 PCC | 0.74377 | 0.743 |
| 문장 완전성 PCC | 0.08691 | 0.109 |

비교 출처: [GOPT 공식 가중치 설명](https://github.com/YuanGongND/gopt/blob/bed909daf8eca035095871e51642525acc5b9b55/pretrained_models/README.md).
PCC는 상관계수이며 정답률이 아니다. 전반적으로 공개 수치에 가깝지만 완전성 등 차이가 있으므로
정확한 재현이라고 표현하지 않는다. 0점 음소를 원본 점수대로 유지한 점(레시피는 0.1 floor),
float32 변환과 환경 차이를 기록한다. 완전성 상관은 낮아서 유용한 완전성 진단의 증거로 쓰지 않는다.
이는 기존 가중치의 실행 검증이며 새로운 모델의 성능 향상이 아니다.

전체 지표·범위·제약: [reproduction.json](reproduction.json).

## 사용자가 실행할 학습의 통합 검증

노트북을 실제 Jupyter 커널로 처음부터 끝까지 실행했다. 자동 검증은 2 epoch로 제한했으며,
사용자 노트북의 기본값은 10 epoch다. 공개 학습 자료 2,500개 중 2,000개/100명으로 학습하고,
500개/25명을 validation으로 고정했다. 별도 시험 자료는 이 학습에서 사용하지 않았다.

| epoch | 학습 음소 MSE | 검증 음소 MSE | 검증 음소 PCC |
|---|---:|---:|---:|
| 0, 학습 전 | 5.36690 | 5.07208 | -0.02125 |
| 1 | 0.14918 | 0.26854 | 0.11426 |
| 2 | 0.14166 | 0.25373 | 0.36189 |

초기 무작위 가중치에서 실제 역전파와 가중치 변경이 일어났다는 확인이다.
최적화된 모델이나 실용적인 개인 발음 평가 성능의 증거는 아니다.
별도의 합성 회귀 테스트와 달리 이 표는 **공개 실제 음성에서 추출한 특징과 사람 점수**를 사용했다.
[설정·로그 요약](smoke.json). 전체 로컬 테스트 84개 통과.

환경: Windows, Python 3.11.4, PyTorch 2.15.0+cpu, NumPy 2.4.6.
공개 자료 다운로드 및 로컬 CPU 계산만 사용했다. 이번 유료 API/GPU 지출 $0.

## 데이터 입수와 감사

원래 저자 Dropbox 링크는 비활성화되어 있었고, 보조 Weiyun 링크는 로그인 단계에서 중단했다.
다른 논문이 제공한 GOP 특징을 임의로 섞으면 같은 84차원이라도 결과가 일치하지 않았다.
최종 사용한 자료는 고정 버전 JazminVidal/gopt-w의 GOPT 형식 파일이며,
5,000개 발화의 ID·음소·음소 점수·단어 점수·문장 점수를 원본 SpeechOcean762와 전부 대조했다.
저장소의 dev/new_te를 재조합해 공식 test를 복원하고, 점수 기반으로 선택한 분할은 사용하지 않았다.

정확한 URL·버전·SHA256: [assets.json](assets.json).
원본 데이터·특징·체크포인트·개인 자료는 Git에 올리지 않는다.
아직 개인 WAV/M4A에서 GOP 특징을 추출하는 기능은 연결되지 않았다.
