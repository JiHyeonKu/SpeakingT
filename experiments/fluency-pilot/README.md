# 실제 음성으로 수행한 첫 유창성 파일럿

2026-10-27. 이것은 개인 발음 교정 모델의 완성이 아니라, 네 가지 저비용 음향 지표로 사람의 유창성 평가를 예측해 보는 **실제 데이터 기준선**이다.

## 데이터와 선택

[SpeechOcean762 공식 저장소](https://github.com/jimbozhang/speechocean762), revision `613968e3b0b789fc33936fb5eba1973176ba7d11`. [OpenSLR 배포 설명](https://www.openslr.org/101/). Zhang et al. (2021), *speechocean762: An Open-Source Non-native English Speech Corpus For Pronunciation Assessment*, Interspeech. 데이터 라이선스: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

변경 사항: seed `20261027`과 ID의 SHA256 순위로 60명에서 각 최대 5개 음성을 선택, 음향 특징 추출, 공개된 문장 유창성 점수(0–10)를 10배하여 0–100으로 변환. 코드는 이 점수를 공개된 사람 평가 집계로 취급한다. 원어민 음성이나 한국인 화자 데이터는 아니다.

공식 train에서 40명은 학습, 10명은 검증, 공식 test에서 10명은 시험에 사용한다. 점수와 특징을 보기 전에 선택을 고정했다. 신뢰할 pitch가 없는 17개는 제외하고 대체하지 않았다. 스크립트에 캐시 해시, 선택 기록, 파일별 제외 이유와 코드 해시가 남는다. 원본 음성·전사·행별 특징은 이 공개 저장소에 복제하지 않는다.

| 분할 | 선택 | 사용 | 화자 | 제외 |
|---|---:|---:|---:|---:|
| 학습 | 200 | 190 | 40 | 10 |
| 검증 | 50 | 47 | 10 | 3 |
| 시험 | 50 | 46 | 10 | 4 |

전체 제외율 5.67%, 시험 제외율 8%. 제외된 어려운 음성에 대한 성능은 이 점수에 포함되지 않는다. 문장 자체가 겹치지 않는 시험은 아직 아니다. 중국어 모국어 화자·아동이 포함된 읽기 자료이므로 한국인 성인 개인·자유 대화로 일반화할 수 없다.

## 학습

입력은 에너지 활동 비율, 긴 내부 휴지 비율, 발화 구간 분당 휴지 수, 상대 pitch의 90–10 백분위 범위. 선형 회귀의 표준화 통계는 학습 데이터에서만 계산한다. 절대 pitch는 입력에 넣지 않는다.

NumPy 2.4.6 / Python 3.11.4 / CPU. Seed `20261027`, 최대 2,000 epoch, patience 100, validation MAE로 선택. **507회에서 종료, 407회 가중치 복원.** 시험 데이터를 보고 특징이나 하이퍼파라미터를 바꾸지 않았다.

## 결과와 해석

| 분할 | 모델 MAE | 학습 평균 예측 MAE |
|---|---:|---:|
| 학습 | 8.405 | 11.042 |
| 검증 | 8.505 | 11.894 |
| 시험 | **10.097** | **11.913** |

절대 오차에는 중앙값 예측도 비교해야 한다. 학습 점수 중앙값 80을 모두에게 예측하면 시험 MAE는 **10.217**이다. 모델의 개선은 약 **0.120점**에 불과하다. 평균 예측만 비교하면 성과를 과장할 수 있다. 중앙값 비교는 시험 후 보고 지표로 추가했으며 모델/epoch를 다시 고르는 데 사용하지 않았다.

이는 작은 시험 표본에서 확인한 기술적 파일럿 결과다. 통계적 유의성이나 유용한 개인 교정 성능을 입증하지 않는다. 현재 결과만으로 채점을 신뢰하거나 '원어민과 얼마나 다른가'를 판정하면 안 된다. 다음 실험은 새 평가 설계를 먼저 고정한 뒤 음소/단어 정렬 및 사전학습 음향 표현을 추가한다.

`model.json`은 이 실험의 작은 계수/표준화/메타데이터 아티팩트이며 원본 음성이 아니다. `summary.json`에는 재현용 해시·규모·평가 지표가 있다. 원본 및 행별 데이터는 제외하지만 파생물에는 출처와 변경 사실을 위와 같이 표시한다. 코드 전체의 라이선스는 별도로 결정하며 데이터 라이선스와 동일하다고 가정하지 않는다.

## 재현

네트워크 다운로드는 공개 원본 저장소에서 선택 파일만 받는다. 이번 다운로드 총량은 약 47.47 MB(메타데이터 포함). 실제 음성과 사람 평가를 사용하며 합성 데모와 별개다.

```powershell
python scripts/prepare_speechocean.py --revision 613968e3b0b789fc33936fb5eba1973176ba7d11 --output-dir data/speechocean762-pilot --seed 20261027
python -m speakingt train data/speechocean762-pilot/manifest.jsonl --output models/speechocean-fluency-pilot.json --max-epochs 2000 --patience 100 --seed 20261027
```

학습된 파일럿 아티팩트 사용(실험용 유창성 추정이며 발음 정확도가 아님):

```powershell
python -m speakingt analyze recordings/mine.wav --fluency-model experiments/fluency-pilot/model.json --output reports/mine.json
```

비용: 유료 API/GPU $0. 다운로드한 데이터·생성 보고서·로컬 모델 폴더는 Git에서 제외한다.
